Never judge a whale by its length!
 Drone-based photogrammetric methods for assessing body size and condition in sperm whales (Physeter macrocephalus) in the Pelagos Sanctuary

This repository contains the Python scripts developed and used for my MSc thesis in Biodiversity and Evolutionary Biology at the University of Milan, carried out in collaboration with CIMA Research Foundation.
The project aimed to estimate sperm whale body size and investigate different body condition indexes using drone-based photogrammetry and computer vision.

- Code overview
The repository includes scripts developed for different stages of the analysis:
- Telemetry synchronization: Python scripts to synchronize drone video recordings with telemetry and altitude data collected using different UAV platforms and sensors.
- Computer vision-assisted measurements: Python scripts using custom-trained YOLO models to assist in detecting sperm whales, selecting suitable video frames and performing morphometric measurements, with manual review and correction.

The scripts were developed specifically for the needs of this research project and were tested and validated during the thesis work.



Generative AI use declaration

Generative AI tools, particularly Claude Code and ChatGPT, were used to assist in writing, implementing and debugging parts of the Python and R code included in this repository.
However, the scientific approach, workflow design, data preparation, methodological decisions and interpretation of the results were carried out by the author.
All AI-assisted code was reviewed, checked and, where applicable, validated by the author through comparisons with independent measurements and other verification procedures.
